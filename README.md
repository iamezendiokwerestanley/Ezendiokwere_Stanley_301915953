## Portfolio Structure

### 📁 [Portfolio 1: Database Design](./portfolio-1-database-design/)
* **Focus:** Relational schema design, normalisation (up to 3NF/BCNF), entity-relationship modeling, and integrity constraints.
* **Contents:** ER diagrams, normalization notes, DDL schema scripts, sample data insertion, and constraint validation tests[cite: 1].

### 📁 [Portfolio 2: Query Optimisation](./portfolio-2-query-optimisation/)
* **Focus:** Execution plan analysis, query tuning, and index strategies for performance enhancement.
* **Contents:** Unoptimised vs. optimised queries, indexing strategies, performance benchmarks, and comparative execution results[cite: 1].

### 📁 [Portfolio 3: Transactions & Concurrency](./portfolio-3-transactions-concurrency/)
* **Focus:** ACID properties, isolation levels, deadlock handling, and multi-session concurrency control.
* **Contents:** Transaction scripts, commit/rollback test suites, parallel session simulations, and concurrency conflict analysis[cite: 1].

### 📁 [Portfolio 4: NoSQL Databases](./portfolio-4-nosql/)
* **Focus:** Document database design, JSON schema validation, and aggregation pipelines using MongoDB.
* **Contents:** MongoDB scripts, document collections, sample queries, and aggregation workflows[cite: 1].

### 📁 [Portfolio 5: Distributed & Cloud Databases](./portfolio-5-distributed-cloud/)
* **Focus:** High availability, sharding, replication, and cloud-native database deployment topologies.
* **Contents:** Architecture design documentation, proposed deployment diagrams, and scaling strategy reports[cite: 1].

3. **Documentation:** Detailed markdown reports and visual diagrams are available within each respective portfolio directory.
